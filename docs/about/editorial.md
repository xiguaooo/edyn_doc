# 编辑与材料说明

## 本站是什么

本站是《伊甸园史记》原始 Word 版本的可浏览重构。它把线性文档分成时间线、四个历史阶段和原始截图档案，以便读者定位、核对和持续补充。

## 材料层级

| 标记 | 含义 | 使用方式 |
| --- | --- | --- |
| 底本文字 | 原作者整理的叙述 | 用于建立事件框架，保留其不确定性措辞。 |
| 原始截图 | Word 内嵌的聊天与公告图 | 作为当时材料公开，按嵌入顺序编号。 |
| 后续补充 | 未来提交的截图、说明或校正 | 需标明日期、来源与改动理由。 |

## 编辑原则

1. **不补造。** 没有材料支撑的细节不写进年表。
2. **不替人定罪。** 争议事件只说明材料中出现的说法、处置与后续变化。
3. **保留更正空间。** 任何参与者都可提交补充材料或请求更正上下文。
4. **文字与截图分开。** 文字帮助理解，截图用于核对；两者都不能自动代替完整事实。

## 截图公开说明

原稿内嵌截图已公开展示于[截图档案](/evidence/)，文件名按原文档的 `imageN` 保留。若截图含有需要补充说明的背景，请在后续修订中增加对应的事件说明和来源标记，而不是只替换图片。

## 建议的贡献格式

提交 issue 或 pull request 时，请包含：事件日期、发生地点（大群/二群/公开动态等）、一段中性摘要、材料文件名，以及你希望新增或更正的文字。涉及他人的材料请先判断是否适合公开。
