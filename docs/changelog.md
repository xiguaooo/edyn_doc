# 更新日志

> 伊甸园史记文档站的版本变更、内容重构与工程实现记录。
>
> 项目仓库：[xiguaooo/edyn_doc](https://github.com/xiguaooo/edyn_doc)

## 2026-11-01

### 性能、响应式与交互打磨

**变更类型：** 性能 / 视觉 / 交互

- **滚动卡顿**：纸纹原本是一层 `position: fixed` + `mix-blend-mode: multiply` 的全屏噪点，等于每一帧都要把整个视口重新混合一次。改为直接画在画布背景上的 SVG 噪声（alpha 已烘进图里），不再产生逐帧合成开销。顶栏与侧栏的 `backdrop-filter` 一并撤掉——纸底接近纯色，模糊本来看不出来，代价却全花在滚动上。
- **图片体积**：新增 `scripts/evidence-thumbs.mjs`（`npm run evidence:thumbs`），为 228 张原图生成 440px 缩略图，首页预览带、图库、正文插图、灯箱缩略图条全部改用缩略图；原图只在灯箱正片和「打开原图」时加载。首页首屏图片传输从 832 KB 降到 205 KB。
- **图库**：卡片加 `content-visibility: auto`，视口外的卡片不再进入渲染树；缩略图条按可视范围懒载，避免开灯箱时 228 张图同时抢连接。
- 首屏逐字动画去掉 `filter: blur()`；章节行 hover 由 `padding-left` 改位移，避免整行重排；阅读进度条改为直接写 `transform`，不再每帧触发组件更新。
- **响应式**：断点重排为 1600 / 1280 / 1180 / 1080 / 900 / 760 / 480，并补 `max-height` 分支（横屏手机、分屏窗口）。超宽屏版心放宽到 1240px 且标题随视口放大；1080 以下标题与说明改为上下结构；手机上按钮等宽、数据行两列。
- **鼠标光晕**：原来挂在 `overflow: hidden` 的 1120px 版心内，光斑靠近左右边界会被切成直边。改为 `Teleport` 到 body 的 `position: fixed` 层，整屏铺开，不再被版心裁切。
- **灯箱**：顶栏重做为「分段缩放控件 + 图标按钮」；遮罩独立成层；缩略图条按需加载；切换图片改为「先解码、后换图」，并在左右各预取两张，消除切换时的空白帧（连按三次下一张，25ms 采样 25 次，空帧 0）。
- **首页**：主按钮改为「读四个章节」，「从时间线读起」降为次级；小标题前的旋转菱形与横线换成朱色空心印记与「壹贰叁」方印；卷首行加延伸细线；数据行加台账列号；章节箭头改为圆形图标；入口卡片加箭头；预览带末尾补「全部」入口。
- **favicon**：上一次导出时把 SVG 当文档截图，浏览器按 1024 固有尺寸渲染，结果只截到左上角。改用 512px 容器页面导出后转 ico。
- 验证：`npx vitepress build docs` 通过；站内链接与锚点 1308 处失效 0；4 倍 CPU 降速下首页滚动 49→61 fps、图库页 37→56 fps。
