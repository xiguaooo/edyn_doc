## 2026-09-20

### 截图编号清单改为自动生成

**变更类型：** 工程实现 / 文档

原先截图总数和扩展名映射表都是手写的，分布在 `evidence.ts`、`EvidenceGallery.vue`、`EvidenceLightbox.vue` 和四处正文文案里。加一张图要同步改五处，漏改就会出坏图或错的计数。

- 新增 `scripts/evidence-manifest.mjs`，扫描 `docs/public/evidence/` 生成 `docs/.vitepress/theme/evidence-manifest.ts`；`npm run docs:dev` 与 `npm run docs:build` 通过 `predev` / `prebuild` 自动执行。
- 删除 `evidence.ts` 里的手写扩展名映射表；`evidenceSource()` 改为查清单，编号不存在时**抛错**而非静默按 `.jpeg` 兜底，写错编号会在构建阶段暴露。
- 脚本在断号、同号多文件、文件名不合规、编号为 0 或带前导零、字母后缀缺主编号、正文引用不存在编号时直接失败；已加图但还没写正文引用时输出提醒。
- 新增 `EvidenceCount.vue`，首页、`截图档案`、`前言与鸣谢`三处的截图总数不再写死。
- 支持字母后缀编号：`image76` 与 `image77` 之间可插入 `image76a`，档案页与灯箱按 `(数字部分, 字母部分)` 排序，翻页顺序正确。此类引用须用静态属性 `id="76a"`，写成 `:id="76a"` 会被当作 JavaScript 表达式而构建失败。
- 同步更新 `README.md` 的目录结构、编辑指南与设计决策记录，以及 `AGENTS.md` 的图片编号约定。
- 验证：`npm run docs:build`；另以临时 `image76a.png` 实测档案页排序、灯箱翻页与计数渲染，随后清理。
