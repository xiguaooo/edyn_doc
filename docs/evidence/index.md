## 怎么用

截图只是材料，不是结论。哪张图缺了日期或前因后果，对照[时间线](/timeline)和章节一起看；还不清楚的，欢迎到仓库里补充。

## 编号规则

编号按时间顺序排，基本等于事件发生的先后。上面每一格标着 `image编号`，和章节正文里的「对应材料」是同一套编号。

后来补进中间的截图用字母后缀，比如 `image76a` 排在 `image76` 和 `image77` 之间，而不是把后面的号全部往前挪——已发布的编号是稳定标识，不会因为加了新图就改变。筛选框输 `76` 会同时命中 `image76`、`image76a` 和 `image176`。

扩展名保留导出时的原样（`.jpeg` / `.jpg` / `.png` 都有），所以直接访问 `/evidence/image编号.扩展名` 就能拿到原图。

新增的续记材料入库时统一转为小写 `.jpeg`，与脚本的大小写判定保持一致。
